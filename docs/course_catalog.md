# Northfield University Course Catalog Excerpt (Sample)

This is a fictional document written for workshop practice.

## CS 210 Data Structures

4 credits. Prerequisite: CS 110. Lists, trees, hash tables, graphs, and algorithm analysis. Offered every fall and spring.

## CS 340 Databases

3 credits. Prerequisite: CS 210. Relational modeling, SQL, indexing, and transactions. Offered every fall.

## CS 415 Introduction to Machine Learning

3 credits. Prerequisites: CS 210 and MATH 220. Supervised and unsupervised learning, model evaluation, and overfitting. Students train models in Python. Offered every fall.

## CS 432 Deep Learning

3 credits. Prerequisite: CS 415. Neural networks, convolutional and transformer architectures, and training practice. Offered every spring.

## DS 301 Applied Data Science

3 credits. Prerequisite: STAT 201. Data cleaning, visualization, and an introduction to machine learning with regression and classification. Offered every spring.

## CS 460 Cloud Computing

3 credits. Prerequisite: CS 340. Virtual machines, containers, managed services, and deployment on a public cloud. Offered every spring.

## MATH 220 Linear Algebra

3 credits. Prerequisite: MATH 120. Vectors, matrices, eigenvalues, and applications. Offered every fall and spring.
